三、核心功能详解

3.1 首页 - D3.js 知识图谱

力导向布局展示校史实体关系网络：46个节点（机构/事件/人物/地点/概念）、45条关系边。支持拖拽、缩放、悬停高亮关联、粒子流动画。

3.2 档案馆 - Three.js 3D 知识图谱

球面布局，可旋转/缩放/点击节点查看详情。支持列表/图谱双模式切换，按分类筛选档案条目，文章内 [[关联条目]] 自动解析跳转。

3.3 校园地图

Leaflet + CRS.Simple 像素坐标系。从官方地图 zoom4 瓦片中提取本部校区 108 张瓦片，PNG 无损拼接为 3072×2816 高清底图。支持拖拽平移、缩放。

3.4 OCR 老照片

使用 Tesseract OCR 识别 90 张校史照片，提取文字后归档为 20 条"老照片"类别档案条目。详情页含图片画廊和模态放大查看。

3.5 推送文集

收录 7 篇微信公众号推送文章，含封面图、多分块导航、微信公众号原文链接。文章数据自动关联到档案库相关条目。

五、迭代历程

从最初的设计概念讨论经过数十轮迭代，涵盖了完整的网站开发流程：技术选型→UI设计→功能开发→内容填充→3D可视化→移动端适配→Bug修复→OCR集成→地图构建。

核心迭代节点：

  • 知识图谱: D3力导向 → Three.js 3D球面 → 过滤人物节点 → 粒子动效
  • 地图: 官方iframe → ImageOverlay拼接 → Leaflet tile层 → zoom4高清瓦片 → PNG无损
  • 档案馆: 文章列表 → 3D图谱模式 → 分类筛选 → 图片画廊 → OCR老照片
  • 部署: GitHub Pages + Actions 自动化流水线
